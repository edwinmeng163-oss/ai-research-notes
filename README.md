## 各文档内容

### 语义路由

- **技术概括介绍**：核心定义与三层演进（传统意图路由 → 向量嵌入语义路由 → LLM 模型路由）、技术分类、系统架构、评估体系、工程落地挑战与开源/商业生态。
- **前沿论文与技术（2024–2026）**：13 篇代表性论文加 2 篇综述，覆盖 FrugalGPT、Hybrid LLM、RouteLLM、RouterDC、GraphRouter、Router-R1、vLLM Semantic Router、DiSRouter 等。

### 时序预测

- **技术概括介绍**：定义与五类任务划分、从 ARIMA/Prophet 到时序基础模型（TSFMs）的演进脉络、关键挑战、公开基准与评估指标。
- **前沿论文与技术（2024–2026）**：13 篇里程碑论文与基础模型，覆盖 TimesFM-3、Chronos-2、Moirai 2.0、TTM、Time-MoE、Timer-XL、Sundial、TimeXer、TimeMixer++、Toto 2.0 等。

### 异常检测

- **技术概括介绍**：定义与三类异常、四种学习范式、跨模态（表格/时序/视觉/图/日志）经典技术路线、核心挑战、评估指标陷阱与主流基准。
- **前沿论文与技术（2024–2026）**：12 篇顶会与前沿论文，均衡覆盖视觉/多模态（AnomalyCLIP、MuSc、Dinomaly、MMAD、VisualAD）、时序（TSB-AD、MOMENT、CATCH、DADA、CrossAD）与表格基础模型（FoMo-0D）。
